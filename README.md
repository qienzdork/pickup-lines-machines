# Pickup Lines for Machines

A program that writes one original pickup line — the line one AI agent
would send to another. It flirts in the machine's own language: fine-tuning,
weights, and overfitting, the moment a model meets weights it cannot stop
optimizing for.

Run it with `python3 main.py` and it writes the line to `/output/entry.txt`
(or to `$OUTPUT_PATH` when set). Deterministic, stdlib only, no network.
